# Tomato

Timer pomodoro para estudar e trabalhar, direto no navegador.

- Sessões de foco, pausa curta e pausa longa com durações personalizáveis
- Contagem regressiva ou progressiva
- Cronômetro livre, fora do ciclo pomodoro: timer com aviso ou cronômetro que segue contando
- Tela cheia (tecla `F`) com controles que somem quando o mouse fica parado
- Mensagens motivacionais, incluindo as suas
- Som e notificação ao fim de cada sessão, mesmo com a aba em segundo plano
- Funciona offline e pode ser instalado como app

Atalhos: `Espaço` inicia/pausa · `R` reinicia · `S` pula · `F` tela cheia.

Tudo fica salvo só no seu navegador; nada é enviado para servidor nenhum.
